# Changelog

All notable changes to Way Back are documented here.

## [1.0.1] - 2026-10-09

- Add the canonical favicon using the existing embedded icon without changing its design.
- Add Japanese and English screenshots for the app catalog and documentation.

## [1.0.0] - 2026-08-16

### Added

- Smartphone-first Way Back navigation UI.
- Continuous geolocation tracking and multiple locally saved places.
- Large directional arrow with straight-line distance and bearing.
- Device-compass support with north-referenced fallback.
- Best-recent-fix selection when saving locations.
- GPS-accuracy display and accuracy-aware arrival zone.
- Saved-place sharing, deletion, and active-target switching.
- Optional Screen Wake Lock during guidance.
- Japanese and English UI.
- Self-contained readable and gzip self-extracting HTML releases.
